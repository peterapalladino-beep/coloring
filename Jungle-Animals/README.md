# Jungle Animals! — Download the book

Open a file below, then click **Download raw file** (the downward arrow) on GitHub. Download it before uploading to KDP.

## Upload these two files to KDP

- [Interior PDF — 84 pages, 40 coloring pictures with blank backs](Jungle_Animals_INTERIOR_84_pages.pdf)
- [KDP wraparound cover PDF — back, spine, and front](KDP_COVER_UPLOAD.pdf)

Settings: paperback, 8.5 × 11 inches, black-and-white interior, white paper, no interior bleed. Confirm the cover dimensions in KDP Print Previewer and order a proof before publishing. Disclose AI-generated artwork during upload.

Use `KDP_COVER_UPLOAD.pdf` for your next paperback cover upload. This version is flattened, CMYK, 300 DPI, PDF 1.3, with no font or transparency dependencies. It has the same wrap dimensions and artwork as the original cover. KDP acceptance still requires an upload check.
